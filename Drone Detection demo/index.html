Reading the comparison

Finding it.
Fitting it.

A detection needs both the right location and a useful bounding box. Tight overlap becomes harder when a drone is only a few pixels wide.

01

mAP50

Measures detection performance at an intersection-over-union threshold of 0.50. It accepts a looser fit between a predicted box and the annotation.

02

mAP50–95

Averages detection performance across ten overlap thresholds, from 0.50 to 0.95. It rewards more precise boxes, while still accounting for missed and extra detections.

“Best” describes these observed checkpoint scores, not a proven advantage across repeated training runs. The two models differ in both detection heads and attention, so this demo does not isolate the effect of either change.

Behind the frames

A closer look at the experiment.

Both YOLOv8n variants combine RGB imagery with a precomputed motion channel after P1. The four-head model uses P2/P3/P4/P5; the other uses P2/P5 with CBAM attention.

All boxes come from saved model outputs. Full-frame views are compressed for playback; the detail panels preserve lossless crops of the original dataset JPEGs. Enlarging a crop adds no new image detail.

Evaluation, selection & source details

ARD-MAV, one drone class. Evaluation: FP32, input size 960, NMS IoU 0.50, maximum 300 detections per image. Aggregate AP uses a confidence floor of 0.001; the visual overlays use the fixed 0.25 threshold. AP and mAP are identical for this one-class task.

The evaluation contains 28,100 drone-present frames from 15 videos. It does not measure false alarms on drone-absent videos. Checkpoints were selected during training using validation mAP50–95; demo model choices use previously examined test scores. Newer pending experiments are not included.

Each example contains 240 consecutive frames present in both prediction exports. Windows favor successful detection by both models; the tiny-target sample also favors annotations below 8 native pixels in √(width × height). No predictions are interpolated or rerun on the crops.

Dataset attribution: ARD-MAV, introduced with Global-Local MAV Detection under Challenging Conditions based on Appearance and Motion. See the dataset source.
