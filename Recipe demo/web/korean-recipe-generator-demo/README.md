# Korean Recipe Generator portfolio demo

This is a generated, static export. Serve the directory as-is from GitHub Pages or another static
host. It requires no build step, backend, API key, model endpoint, or GPU.

The bundled live inventory contains seven verified recipe references from the frozen Stage 7
showcase. EPIS/MAFRA-derived recipe text retains source attribution and its attribution/share-alike
condition. Korean Food Promotion Institute recipe text retains KOGL Type 1 attribution. The site
displays and links provenance for each recipe.

Source project: <https://github.com/rjc1998/COMP_597_NLP-Recipe_Generator>
